# Поиск минимального остовного дерева

Проект содержит программу для построения минимального остовного дерева взвешенного неориентированного графа и тесты для проверки её работы.

## Файлы проекта

- `solution.py` — основная программа. Реализует алгоритм Прима и записывает результат в `out.txt`.
- `test.py` — тестирующая программа. Создаёт входной файл `in.txt`, запускает `solution.py` и проверяет общий вес дерева и количество строк результата.
- `in.txt` — входные данные, которые читает основная программа.
- `out.txt` — выходные данные, которые формирует основная программа.

## Требования

- Python 3.
- Файлы `solution.py` и `test.py` должны находиться в одной папке.

## Формат входных данных (`in.txt`)

В первой строке задаётся число `n` — количество вершин графа. Далее записывается матрица смежности размера `n × n`, содержащая веса рёбер.

Например, для графа из трёх вершин:

```text
3
0 1 3
1 0 2
3 2 0
```

В этом примере ребро между вершинами 1 и 2 имеет вес 1, между вершинами 2 и 3 — вес 2, а между вершинами 1 и 3 — вес 3. Нумерация вершин во входной матрице начинается с 1 в описании, а в коде используется индексация с 0.

Предполагается, что граф неориентированный, поэтому матрица весов симметрична, и граф связный. Нулевые значения на главной диагонали обозначают отсутствие петель.

## Формат выходных данных (`out.txt`)

Первые `n` строк содержат списки соседей каждой вершины в построенном остовном дереве. Номера вершин выводятся с 1, а `0` завершает список соседей.

Последняя строка содержит суммарный вес рёбер минимального остовного дерева.

Для приведённого выше примера возможен такой результат:

```text
2 0
1 3 0
2 0
3
```

При равных весах рёбер могут существовать несколько минимальных остовных деревьев, поэтому конкретный список рёбер может отличаться, но общий минимальный вес должен совпадать.

## Как запустить основную программу

1. Поместите входные данные в файл `in.txt`.
2. Выполните команду в терминале из папки проекта:

   ```bash
   python solution.py
   ```

3. Посмотрите результат в файле `out.txt`.

В зависимости от настройки системы вместо `python` может понадобиться команда `python3`.

## Как запустить тесты

Выполните:

```bash
python test.py
```

Тестирующая программа последовательно запускает пять тестов:

| Тест | Что проверяется | Ожидаемый вес |
|---|---|---:|
| 1 | Граф с одной вершиной | 0 |
| 2 | Граф с двумя вершинами | 5 |
| 3 | Граф с тремя вершинами | 3 |
| 4 | Граф с четырьмя вершинами | 6 |
| 5 | Граф, в котором все рёбра имеют одинаковый вес | 4 |

Для каждого теста выводится статус `OK` или `ОШИБКА`. Тесты проверяют количество строк в выходном файле и, где указан ожидаемый результат, суммарный вес дерева. Они **не проверяют полностью** корректность структуры дерева и списков соседей.

## Как работает алгоритм

Программа использует алгоритм Прима:

1. Начинает с вершины с индексом `0`.
2. Для каждой ещё не включённой вершины хранит вес минимального известного ребра, соединяющего её с уже построенной частью дерева.
3. Добавляет вершину, для которой этот вес минимален.
4. Обновляет ближайших соседей оставшихся вершин.
5. Повторяет действия, пока не будут добавлены `n - 1` рёбер.

Алгоритм строит минимальное остовное дерево связного взвешенного неориентированного графа.

## Ограничения текущей реализации

- Программа предполагает, что граф связный и матрица весов симметрична.
- Для начального значения расстояния используется `32767`, поэтому веса и минимальные расстояния должны укладываться в ограничения этой реализации. Для больших весов начальное значение лучше заменить на `float('inf')`.
- Если граф несвязный или входные данные некорректны, программа не выполняет отдельную проверку и может сформировать неверный результат или завершиться с ошибкой.
- Тестирующая программа использует общий вес и количество строк как основные критерии, поэтому она не гарантирует, что каждое ребро и список соседей корректны.
